
# Replikacja projektu

## Instalacja

```bash
pip install -r requirements.txt
```

## Uruchomienie treningu

```bash
python main.py
```

## Notebook

Uruchom:
```bash
jupyter notebook
```

następnie:
```txt
notebooks/model_training.ipynb
```

## Dataset

Dataset należy umieścić w:
```txt
data/train.csv
```

lub użyć:
```txt
data/raw/Car_Prices_Poland_Kaggle.csv
```
